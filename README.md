# ERP migration analytics
Étude de cas : garder des indicateurs fiables pendant la migration ERP d'un groupe industriel multi-filiales.
Données synthétiques. Stack : Python, PostgreSQL, Airbyte, BigQuery, dbt, Power BI.

La conception du projet (conventions, modèle de données, règles métier) est documentée dans [`docs/`](docs/README.md).
